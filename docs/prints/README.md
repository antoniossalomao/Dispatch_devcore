# Prints do Dispatch

Abra `index.html` no navegador para ver a galeria. Clique em uma miniatura para abrir o PNG completo. `visao-geral.png` reúne as nove telas principais.

São 39 capturas de desktop (1440 × 1000, com página inteira quando necessário) e 17 de celular (390 × 844). O pacote inclui as abas de Relatórios e Configurações, Auditoria, cadastros, históricos, alojamentos, frota, notificações e ajuda. As capturas usam dados fictícios de demonstração.

A tela de apresentação e seus arquivos não foram alterados.
